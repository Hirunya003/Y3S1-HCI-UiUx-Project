# 🚆 Sri Lankan Railway Website Redesign - (Y3S1 University Project)

## 📌 Project Overview
This project is a UI/UX redesign of the **Sri Lankan Railway website**, completed as part of the *Human Computer Interaction (HCI)* module.

The goal was to identify usability issues in the existing system and improve the user experience through user research, low-fidelity sketches, and high-fidelity designs.

---

## 🎯 Problem Statement
The existing Sri Lankan Railway website presents challenges such as unclear navigation, outdated layouts, and difficulty in finding essential passenger information.

---

## 👤 Target Users
- Daily railway passengers  
- Occasional travelers  
- First-time website users  

---

## 🧠 My Role (Individual Contribution)
This was a **group project**, and my responsibility focused on the following interfaces:

- **Contact Us Page**
- **FAQ Page**
- **Passenger Services Page**

My contributions included:
- Usability issue identification
- Persona-based analysis
- Low-fidelity sketching
- High-fidelity UI design

---

## 🛠 Tools Used
- Figma  
- Pen & Paper (Low-fidelity sketches)

---

## 🔄 Design Process
1. Conducted contextual inquiries with users  
2. Identified usability issues and pain points  
3. Created personas based on different passenger types  
4. Designed low-fidelity sketches  
5. Developed high-fidelity UI designs
